# BIOFLOW: исправления пользовательского аудита, 09.10.2026

Исправлены 23 подтверждённых дефекта Web из аудита. Повторные проверки через Chromium: **23/23 успешны**, 0 неуспешных. Обход: **221 экранов по 11 ролям**, 0 экранов с HTTP/JavaScript-ошибками.

Проверка проводилась на изолированной копии с синтетическими данными: PostgreSQL `bioflow_uat` и отдельная `bioflow_fixes_spec`, собственные Redis/S3, API 4140, Web 3040. Итоговый UI-прогон использует production-сборку Web, подключённую только к локальному API. Обновлён Next.js до 16.3.8. Исходный аудит и исходное ТЗ сохранены.

Изменения находятся в локальной ветке `codex/ui-audit-fixes`. Сервер, main, публичные релизы и рабочие данные не изменялись.

## Проверки кода и API

- Prisma generate и OpenAPI generate прошли; новые явные маршруты справочников отражены в контракте.
- Общие lint, test и production build прошли.
- 51 backend unit-тест, 7 Web-тестов защиты сессий и обработки ошибок сети, 1 тест API-контракта прошли.
- 20 реальных HTTP-проверок на отдельной PostgreSQL и приватном S3 прошли: партийный цикл, массы, QR, фото, расхождения, отмены, производство, прослеживаемость, экспорты, конкуренция и объектные права. Добавлены проверки уведомлений/аудита, настроек и ошибок справочников.
- `npm audit --omit=dev --audit-level=high` проходит: высоких/критических уязвимостей нет. Остаются 2 moderate-записи цепочки Swagger → js-yaml; автоматический фикс предлагает Swagger 12 вместе с NestJS 12 с изменением major-версий. Этот отдельный переход не включён в исправления UI.

## Границы проверки

Android через интерфейс по-прежнему не проверен: нет подключённого устройства или эмулятора. Старая опубликованная APK не пересобиралась и не заменялась. Проверки Web не подтверждают работу Android.

Этот повторный прогон закрывает 23 выявленных дефекта и проверяет доступные экраны всех ролей. Он не повторяет каждый из 150 первоначальных сценариев и каждую комбинацию роль × операция × назначение. Расширенный ролевой обход проверяет открытие экранов; бизнес-действия проверены целевыми UI-сценариями и HTTP-приёмкой.

Не проверены мобильный Web и другие браузеры, реальная доставка Firebase push, камера/галерея Android, HTTPS/DNS рабочего домена, нагрузка, резервное восстановление на сервере и полное визуальное сравнение всех Figma-экранов. Публикация и production-приёмка не выполнялись.

# BIOFLOW исходные материалы для разработки

Комплект от 5 октября 2026 года для среды bioflow. Он содержит исходное техническое задание проекта «контроль качетсва», актуальный индекс Figma, выбранные синие дизайн-референсы и рабочие требования для проверки приложения.

## Что читать сначала

1. docs/CURRENT_BRIEF.md - текущие требования, ограничения и различия источников.
2. sources/Техническое_задание_учет_биоматериала.docx - исходное ТЗ, сохранено без изменения.
3. design/FIGMA_SCREENS.md - точные ссылки на 13 текущих экранов Figma.
4. docs/ACCEPTANCE_CHECKLIST.md - критерии проверки AT 01-13 и дополнительные проверки ограничений.
5. INDEX.md - происхождение и статус каждого включённого материала.
6. IMPORT_TASK.txt - задание на добавление этого комплекта в репозиторий без изменения кода приложения.

## Главные решения

- Продукт BIOFLOW: учёт биоматериала от добычи до готовой продукции.
- Использовать только синий вариант NAVY & PLATINUM.
- GPS, карты, маршруты и отслеживание водителя исключены.
- QR относится к транспортной накладной и связывает перевозку, партию и автомобиль.
- Актуальный дизайн: https://www.figma.com/design/dG2YQGuVA9ZG2QStcBL5Ag
- PDF от 25 сентября - более ранние референсы. Они не отменяют позднюю Figma и полное ТЗ.
- Демонстрационные цифры и названия в макетах не являются данными заказчика.

## Полнота

ТЗ, 13 ссылок и текстовая структура текущих Figma-экранов доступны полностью. Сохранён PNG главного мобильного экрана. Остальные актуальные PNG и отдельные SVG/иконки не экспортированы: достигнут лимит Figma. Для просмотра остальных экранов используйте их прямые ссылки. В комплекте есть два синих PDF-референса предыдущей версии.

Полный дословный Codex-промпт от 29 сентября не удалось извлечь. CURRENT_BRIEF содержит проверяемые требования из ТЗ, актуальной Figma и восстановленные решения из обсуждения; он не выдается за копию того промпта.

Комплект не подтверждает реализацию функций, успешное тестирование, выпуск приложения или добавление файлов в репозиторий. Это исходные материалы и критерии последующей проверки.

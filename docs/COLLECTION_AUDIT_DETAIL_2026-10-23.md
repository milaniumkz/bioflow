# Завершение карточки аудита Collection

Основная версия дизайна объединена PR №16 и выложена штатным server-ops workflow: commit `4ebf2c346d4c8cd8a5d3adb04336fc5c28ad2e47`, run `39905593778`. Семь публичных проверок подтвердили Web на 390/1440, загруженный согласованный шрифт/лицензию, отсутствие overflow/client errors, health БД/Redis и запрет неавторизованного доступа к новым реестрам. APK не собирался.

Финальная сверка W22A выявила пропуск: карточка показывала метаданные события, но не сохранённые значения. Добавлена readonly-карточка «Было / стало» с действительными различиями, сохранением нулей/false/удалённых полей, вложенными фактами и именованными складами/местами добычи/контрагентом. Действия выбираются по русским названиям; пользовательское имя показывается вместо ID там, где есть разрешённый контекст.

Чувствительные поля маскируются в выдаче аудита и обоих путях экспорта, включая вложенные и snake_case ключи. `mustChangePassword` допускается как boolean; пароль, хеш, токен, ключ, код восстановления не выводятся. Исходные неизменяемые записи аудита не переписываются. Проверка маскирования CSV подтверждает отсутствие синтетических секретов в ответе.

Ограниченный `audit.read` caller получает свои события внутри организации; организация/actor остаются обязательными условиями при поиске. Разрешённые имена объектов резолвятся внутри актуального scope. Общие записи доступны пользователю с существующим `accessAllObjects`. Сохранённые права/назначения не менялись; новых миграций нет.

Проверено: workspace lint/build, **71 backend-тест / 17 suites**, **22 Web-теста**, реальная PostgreSQL-интеграция назначения доступа/истории/области, **3 Chromium-проверки карточки** (до/после/имена, 1440/390, Esc с сохранением фильтра), повтор кабинета/отчётов. Flutter-код этой доработкой не изменён; ранее прошли 34 Flutter-теста и компиляция Kotlin без APK. GitHub CI снова запускается с `skip_apk=true` перед выкладкой дополнения.

Исходное ТЗ/manifest сохранены. Матрица всех 157 вариантов синхронизирована с актуальными компонентами и ограничениями. Аппаратные Android camera/Doze/FCM/system sheets и отдельная pixel-приёмка всех PNG не выдаются за выполненные тесты. Серверная выкладка обновляет Web/API, не установленный нативный бинарник.

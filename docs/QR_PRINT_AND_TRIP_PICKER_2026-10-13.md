# Печать QR и выбор партии в перевозке — 13.10.2026

Кнопка «Печать QR» вызывала печать всей страницы без правил для печати. Теперь QR выводится в отдельный элемент непосредственно в body. В режиме печати интерфейс, окно сохранения, кнопки и QR-токен скрываются; остаётся один QR размером 50 × 50 мм на белом фоне. На экране этот элемент скрыт и удаляется при закрытии подтверждения.

Новая партия сохраняется как черновик. Backend разрешает перевозки только из подтверждённых/частично отгруженных партий с доступным остатком; это правило сохранено. Раньше черновики просто отсутствовали в выборе без объяснения. Теперь они видны как недоступные варианты с пояснением «черновик — сначала подтвердите», рядом есть инструкция и переход к партиям добычи для пользователей с правом подтверждения. Закрытые, отменённые и партии без остатка не предлагаются. Ошибка загрузки справочников показывается явно.

Справочник партий раньше ограничивался первыми 100 записями. Теперь Web загружает все страницы доступных пользователю партий; права и области доступа API не изменены.

## Проверка

Изолированная production-сборка Web, настоящий API/PostgreSQL, HTTP-контекст браузера. Рабочие записи сервера не использовались.

- Создание партии через форму: 201, окно с QR.
- Chromium print media: интерфейс/диалог скрыты, QR виден; PDF имеет одну страницу, одно изображение и пустой текстовый слой. Просмотр растеризованного PDF подтвердил только QR на белой странице. После возврата к screen media диалог виден; после закрытия печатный элемент удалён.
- Перевозка: черновик виден с пояснением и disabled; через UI партия подтверждена, стала доступна; перевозка создана через форму, 201, видна в списке.
- Более 100 записей: подтверждённая партия отсутствует на первой странице API, но доступна в Web; браузер загрузил page=2.
- JavaScript-ошибок нет. Web build, TypeScript lint и 11 существующих Web-тестов прошли.

Артефакты текущего запуска: `/workspace/artifacts/bioflow-qr-trip-2026-10-13`. Физический принтер и Android не проверялись в этой правке. Параметры печати браузера (бумага, масштаб, колонтитулы) пользователь выбирает в системном диалоге.

## Как создать перевозку

1. В «Партии добычи» найдите созданную партию.
2. Если статус «Черновик», нажмите «Подтвердить», заполните причину и подтвердите действие.
3. Закройте окно сохранения, откройте «Перевозки» → «Новая перевозка из партии».
4. Выберите партию, транспорт и склад назначения, укажите объём и дату с временем. Нажмите «Создать».
5. При отсутствии права подтверждения попросите ответственного пользователя подтвердить партию. Объём перевозки не должен превышать доступный остаток.

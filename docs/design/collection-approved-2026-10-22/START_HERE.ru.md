# Collection: утверждённый дизайн → внедрение в Codex

Дизайн согласован пользователем 22 октября 2026 года. Этот пакет передаёт визуальное решение и требования к реализации. Он не является готовым приложением, проверкой готовности backend или разрешением на публикацию.

## Как использовать

1. Прикрепите `Collection_Codex_Handoff.zip` к задаче Codex в актуальном репозитории Collection / бывшем BIOFLOW.
2. Вставьте содержимое `CODEX_PROMPT.ru.txt`. Промпт также приложен отдельным файлом.
3. Для точного сравнения отдельных экранов можно дополнительно прикрепить оба архива `Collection_Reference_PNG_Mobile.zip` и `Collection_Reference_PNG_Web.zip`. Они распаковываются в ту же папку `Collection_Codex_Handoff/references/png/`. Основной архив уже содержит оба полных PDF-каталога, поэтому PNG не обязательны для начала работы.

## Что считать источником правды

- Утверждённая композиция: `references/pdf/Collection_Design_Mobile.pdf` и `Collection_Design_Web.pdf`, а также PNG из дополнительных архивов.
- 59 семейств, 157 конкретных макетов/состояний: `specs/SCREEN_MANIFEST.json`. Семейство не равно отдельной новой странице или отдельному приложению для роли.
- Поведение, расчёты и безопасность: `specs/WORKFLOWS_AND_SECURITY.ru.md`. Если демонстрационные числа или подписи расходятся с правилами, исправлять поведение по правилам, не переносить ошибку в продукт.
- Навигация и роли: `specs/ROUTES_AND_ROLES.ru.md`, компоненты: `specs/COMPONENTS_AND_NAVIGATION.ru.md`.
- Точные визуальные параметры: `specs/design-tokens.json` и исходный CSS.
- Критерии готовности: `specs/ACCEPTANCE_CHECKLIST.ru.md`.

## Важная оговорка о шрифте

В утверждённых изображениях использован **OpenAI Sans Cyrillic** (Dinamo Typefaces). Исходные файлы этого шрифта не включены: в найденной встроенной лицензии запрещена повторная раздача. Точное имя сохранено в токенах. PDF/PNG остаются визуальным эталоном.

Для локального просмотра HTML приложен **Open Sans** с Apache License 2.0. Это явно обозначенная временная замена для предпросмотра, а не утверждение нового шрифта для продукта. Codex должен сначала проверить наличие и разрешённое использование исходного шрифта в текущем проекте. Если это невозможно, предложить лицензируемую замену и получить согласование до существенного изменения типографики. Не извлекать шрифт из PDF/галереи и не копировать его из сторонних приложений.

## Файлы

- `design/index.html`: галерея на локальных файлах; формы внутри являются статическими макетами.
- `design/Collection_Design_Gallery.html`: автономная галерея всех 157 макетов, с обозначенной заменой шрифта.
- `design/*.js`, `design/gallery.css`: исходники представления. Не готовая архитектура production.
- `design/reference-original.css`: исходные параметры утверждённого оформления, без проприетарных файлов шрифта.
- `design/static/*.html`: отдельные страницы для каждого ID.
- `assets/logo/collection-symbol.png`: точный утверждённый символ без номера «01». Wordmark остаётся живым текстом `collection`.
- `assets/icons/*.svg`: использованные линейные иконки, по одной на файл.
- `design/assets/fonts/`: только разрешённые к распространению файлы Open Sans; лицензии в `licenses/`.
- `specs/COVERAGE_AND_LIMITATIONS.ru.md`: покрытие, границы и известные вопросы реализации.
- `specs/SOURCE_HASHES.sha256`: контрольные суммы файлов основного архива.
- `tools/validate_package.py`: локальная проверка состава, контрольных сумм, ID и ссылок.

## Границы поручения

Не собирать Android APK. Не делать релиз, deployment, публикацию, destructive reset, удаление пользовательской работы, изменение доступа или применение новых миграций без отдельного разрешения. Веб-сборка, статический анализ, тесты и локальная проверка UI допустимы. Реальный backend, роли, очередь offline, GPS и QR должны работать, а не имитироваться красивыми экранами.

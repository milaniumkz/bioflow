# Обратная связь при создании партии — 12.10.2026

После исправления HTTP UUID сохранение могло выглядеть как отсутствие реакции: нативная HTML-проверка блокировала submit при незаполненном способе измерения/дате без сообщения в приложении, а подтверждение успешной операции находилось ниже списка документов.

Форма партии теперь явно проверяет обязательные поля и сообщает по-русски, какое поле нужно заполнить. Сообщение прокручивается в видимую область. Дата проверяется до преобразования в ISO; данные считываются из текущих элементов формы. Ошибки API также прокручиваются в видимую область. После успешной ledger-команды открывается окно «Документ сохранён» с номером и QR; подтверждение больше не скрывается под списком.

Проверено на production-сборке Web с настоящим изолированным API/PostgreSQL: пустой способ измерения и пустая дата показывают сообщения, POST не отправляется; заполненная форма получает 201, открывает окно с номером, после закрытия в списке ровно одна запись. JavaScript-ошибок нет. Снимки: /workspace/artifacts/bioflow-feedback-2026-10-12. Рабочие записи сервера не использовались для UI-тестов. Изменений схемы БД и прав доступа нет.

Пользователю: заполните подрядчика, место добычи, материал, объём, способ измерения и дату **с временем**. Нажмите «Создать черновик». При пропуске появится пояснение, при сохранении — окно с номером. Закройте его, чтобы продолжить работу со списком.
